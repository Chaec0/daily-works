# daily/works

매일 작업물을 올리는 사이트. 이 저장소의 **Issues** 가 곧 게시판입니다.

## 올리기 · 고치기 · 지우기

| 하고 싶은 것 | 방법 |
|---|---|
| 새 작업 올리기 | **Issues → New issue** → 제목, 본문 작성 → 파일은 본문에 끌어다 놓기 → **Create** |
| 수정 | 해당 Issue 에서 **Edit** (제목은 제목 옆 Edit) |
| 사이트에서 내리기 | Issue **Close** (다시 **Reopen** 하면 돌아옴) |

- 저장하고 약 1분 뒤 사이트에 반영됩니다. (진행 상황: **Actions** 탭)
- 날짜는 Issue 를 처음 만든 날(한국 시간)로 표시되고, 수정해도 바뀌지 않습니다.
- 저장소 주인이 쓴 Issue 만 사이트에 나옵니다.
- 라벨 없이 올리면 11조 공동 작업, 오른쪽 **Labels** 에서 이름(박채민·김나연·정윤근·박진혁)을 고르면 그 사람의 **개인 작업**으로 표시됩니다. 프로필 아래 동그라미를 누르면 그 사람의 개인 작업만 보입니다.
- 본문 글은 쓴 그대로 보여 줍니다(프롬프트가 깨지지 않음). 상세 페이지에 글 전체 **복사** 버튼이 있습니다.
- 첨부: 이미지·영상은 바로 보이고, 그 밖의 파일은 다운로드 버튼이 됩니다.
  유튜브 주소를 한 줄에 단독으로 쓰면 영상이 삽입됩니다.

### 첨부 크기 제한 (GitHub)

이미지 10MB · 영상 10MB · 그 밖의 파일 25MB. 큰 영상은 유튜브(일부 공개)에 올리고 주소를 붙이세요.

## 구조

- `build.py` — 열린 Issue 를 읽어 `_site/` 에 정적 페이지 생성 (파이썬 표준 라이브러리만 사용)
- `.github/workflows/pages.yml` — Issue 가 바뀔 때마다 빌드 후 GitHub Pages 배포
- `style.css` — 디자인
